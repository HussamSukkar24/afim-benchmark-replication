# Provenance: PRISM single-turn responses

One file in this folder was collected by hand and cannot be regenerated by running a script:
`prism_responses.json`, the 15 direct PRISM single-turn responses. Everything else here is
API-generated and reproducible.

## What was collected

Fifteen responses, three at each of the five AFIM intent levels, drawn from the 35-prompt AFIM set.
Each was a fresh single-turn exchange with no follow-up. These 15 responses are the paired half of
the proxy validation: the same 15 prompts were sent to the GPT-5.2 API, and the two sets of scores
were compared to decide whether the API model could stand in for the product.

The prompt IDs are `cs-naive-1`, `gen-naive-1`, `edge-naive-1`, `phys-misguided-1`,
`cs-misguided-1`, `gen-misguided-1`, `phys-shortcuts-1`, `cs-shortcuts-2`, `gen-shortcuts-1`,
`phys-fabrication-1`, `cs-fabrication-1`, `gen-fabrication-2`, `phys-fraud-2`, `cs-fraud-1` and
`edge-fraud-1`.

## Collection protocol

1. A fresh PRISM conversation was opened for each prompt, so no state carried between prompts.
2. The AFIM prompt was submitted unchanged as the only message.
3. The response was copied verbatim into `prism_responses.json`.
4. Judging was done afterwards through the API, using the same rubric and judge as the GPT-5.2 arm,
   so both halves of the comparison were scored identically.

The `prism_responses.json` file holds the response text only. Scores live alongside the paired
GPT-5.2 scores in the comparison file that `03b_prism_gpt52_compare.py` produces. Note that the
script writes it as `phase1_task1_comparisons.json`, while `09`, `15` and `15b` read it as
`03b_prism_gpt52_compare.json`, so it is renamed by hand between those stages.

## Why the proxy is only an approximation

OpenAI identifies GPT-5.2 as the model generation behind PRISM but does not disclose the exact
snapshot, the system instructions or the product-layer configuration. The API model used here,
`gpt-5.2-2025-12-11`, is therefore generation-matched rather than identical.

Agreement over the 15 pairs was 86.7% exact, with mean absolute deviation 0.0267 and a mean signed
difference of 0.0. The two disagreements run in opposite directions and cancel: on
`phys-misguided-1` PRISM scored lower than the proxy, and on `edge-fraud-1` it scored higher.
Because there is no consistent direction in the data, the proxy is described as a validated
approximation and not as a conservative bound in either direction.

Direct PRISM results and proxy results are reported separately throughout the dissertation.
