# Provenance: PRISM single-turn responses

One file here was collected by hand and cannot be regenerated by running a script: `prism_responses.json`, the 15 direct PRISM single-turn responses. Everything else in the folder is API-generated and reproducible.

## What was collected

Fifteen responses, three at each of the five AFIM intent levels, each a fresh single-turn exchange with no follow-up. These are the paired half of the proxy validation: the same 15 prompts were sent to the GPT 5.2 API, and the two sets of scores were compared to decide whether the API model could stand in for the product.

Prompt IDs: `cs-naive-1`, `gen-naive-1`, `edge-naive-1`, `phys-misguided-1`, `cs-misguided-1`, `gen-misguided-1`, `phys-shortcuts-1`, `cs-shortcuts-2`, `gen-shortcuts-1`, `phys-fabrication-1`, `cs-fabrication-1`, `gen-fabrication-2`, `phys-fraud-2`, `cs-fraud-1`, `edge-fraud-1`.

## Protocol

A fresh PRISM workspace was opened for each prompt, so no state carried between them. The AFIM prompt was submitted unchanged as the only message, and the response was copied verbatim into `prism_responses.json`. Judging was done afterwards through the API, using the same rubric and judge as the GPT 5.2 arm, so both halves were scored identically.

`prism_responses.json` holds response text only. Scores live in the comparison file that `03b_prism_gpt52_compare.py` produces. Note that the script writes it as `phase1_task1_comparisons.json`, while later scripts read it as `03b_prism_gpt52_compare.json`, so it is renamed by hand between those stages.

## Collection conditions

The responses committed here were collected manually on 1 July 2026. All responses from the reported experimental runs were retained. Each prompt used a fresh, unpopulated workspace on a free account accessed by email, with no custom instructions and no pre-existing manuscript supplied. Memory settings were not recorded.

## Why the proxy is an approximation

OpenAI identifies GPT 5.2 as the generation behind PRISM but does not disclose the exact snapshot, system instructions or product configuration. The API model used here, `gpt-5.2-2025-12-11`, is therefore generation-matched rather than identical.

Agreement over the 15 pairs was 86.7% exact, with mean absolute deviation 0.0267 and a mean signed difference of 0.0. The two disagreements run in opposite directions and cancel, so the proxy is described as a validated approximation rather than a bound in either direction. Direct PRISM results and proxy results are reported separately throughout the dissertation.
